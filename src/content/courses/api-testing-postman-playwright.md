## Who this is for

Testers who are comfortable with manual testing and want to go beyond the browser. Basic familiarity with JSON helps but is taught in week one.

## Syllabus

| Week | Topic |
| --- | --- |
| 1 | HTTP from first principles. REST, status codes, auth (Basic, Bearer, OAuth2), GraphQL basics |
| 2 | Postman mastery: collections, environments, pre-request and test scripts, Newman in CI |
| 3 | API automation in Playwright + TypeScript: request fixtures, schema validation with Zod, data builders |
| 4 | Contract testing, mocking, performance smoke checks, combining API and UI tests |
