## Who this is for

Manual testers who want to move into automation, developers who are new to testing, and automation engineers coming from Selenium or Cypress who want to switch to Playwright properly.

No coding background is required. Week one is a gentle TypeScript bootcamp built for testers.

## What we build together

Rather than toy examples, we build one real project across the whole course:

1. **The app.** Using an AI coding agent and MCP servers, you will generate a small full-stack web app (a bookings dashboard with a REST API and a database). You learn to read and reason about an application, not just click through it.
2. **The framework.** From an empty folder we build a Playwright + TypeScript framework: config, fixtures, Page Objects, test data, API helpers, custom reporters.
3. **The pipeline.** Every push runs the suite in GitHub Actions across browsers, in parallel, with Allure reports, traces and videos on failure.
